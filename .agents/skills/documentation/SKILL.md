# Documentation

- Update the nearest authoritative document rather than duplicating guidance.
- Keep service responsibility, interfaces, dependencies, non-goals and safety rules explicit.
- Use ADRs for consequential decisions and state their status and consequences.
- Link repository-specific docs from the workspace service index.
- Use fictitious examples and never publish secrets or personal data.
