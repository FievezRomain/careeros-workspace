# AI engineering

- Treat model output as untrusted and validate it against schemas and verified profile facts.
- Route provider access through the AI gateway; never embed provider credentials.
- Record model/prompt versions, latency, cost metadata and non-sensitive evaluation evidence.
- Redact unnecessary personal data before requests and define retention expectations.
- Provide deterministic fallbacks for safety-critical or approval-gating decisions.
