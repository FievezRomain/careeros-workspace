# API contracts

- Prefer additive evolution and explicit versioning.
- Define error shapes, pagination, idempotency and authorization semantics.
- Use fictitious examples without personal data.
- Validate schemas in CI and add consumer-focused contract tests.
- For breaking changes, document migration, deprecation and coordinated rollout.
