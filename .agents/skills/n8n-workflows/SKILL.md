# n8n workflows

- Export workflows without credentials, tokens, webhook secrets or production identifiers.
- Reference credentials by configured names and document required variables separately.
- Make retried steps idempotent and define bounded retries and failure paths.
- Put an explicit user-approval gate before messages, calendar changes or applications.
- Log correlation and outcome metadata without sensitive payloads.
