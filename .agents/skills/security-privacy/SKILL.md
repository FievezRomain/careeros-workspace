# Security and privacy

- Minimize collected data and document purpose, provenance, retention and deletion.
- Enforce ownership and tenant isolation server-side for every resource access.
- Keep secrets in environment-specific secret stores; repositories contain placeholders only.
- Redact logs and never use real CVs, applications or contact details as fixtures.
- Require explicit approval immediately before external messages, applications or destructive actions.
