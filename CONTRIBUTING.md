# Contributing

1. Open an issue or discussion for significant behavioral or contract changes.
2. Keep changes scoped and update documentation and tests together.
3. Use fictitious data only. Run secret scanning before pushing.
4. Preserve backward compatibility or document an explicit migration.
5. Do not enable external communication, application submission or destructive automation without explicit user approval at action time.

By contributing, you agree that your contribution is licensed under Apache-2.0.
